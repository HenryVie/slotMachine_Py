The project idea was from Tim Ruscica (a.k.a Tech with Tim).

This is one of my first ever Python project, I wanted to do something that's cool and one day, I saw Tim's video on YouTube about building a terminal-based slot machine.
I decided to watch his video all in one go and then started to code my own one by my own.

What it includes:
- Betting system & balance control
- Weighted symbol probabilities
- Reel spinning logic
- Win detection across multiple rows
- Clean game loop & replay flow
